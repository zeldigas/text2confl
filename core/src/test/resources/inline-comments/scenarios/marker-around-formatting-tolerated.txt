other editors (e.g. Data Center, not verified yet) might. The comment is read correctly and written in Cloud form

<p>Use {c1:<em>very</em> careful:} steps.</p>
=== generated
<p>Always use <em>very</em> careful steps.</p>
=== expected
<p>Always use <em>{c1:very:}</em>{c1: careful:} steps.</p>
